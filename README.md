
# GitHub Lab - Gestor de Tareas

Aplicación web sencilla desarrollada para practicar
Git, GitHub y el trabajo colaborativo.

## Objetivo

Aprender a gestionar el ciclo de desarrollo de software,
desde la creación de un Issue hasta su integración
mediante un Pull Request.

## Funcionalidades

- Visualizar tareas de ejemplo.
- Agregar nuevas tareas desde la interfaz.
- Evitar que se agreguen tareas vacías.

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Git y GitHub

## Cómo ejecutar el proyecto

1. Clonar el repositorio.
2. Abrir la carpeta del proyecto.
3. Abrir `index.html` en un navegador.

## Flujo de trabajo

1. Crear un Issue.
2. Crear una rama de desarrollo.
3. Implementar los cambios.
4. Realizar commit y push.
5. Abrir un Pull Request.
6. Revisar y probar los cambios.
7. Integrar el PR a `main`.
